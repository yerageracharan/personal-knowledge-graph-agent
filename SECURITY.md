# Security Policy

This project may process private notes and personal documents. Do not publish private documents, credentials, tokens, or exploitable details in public issues or pull requests.

Use GitHub's Security tab and **Report a vulnerability** flow for private disclosure when enabled. If unavailable, contact the repository owner privately through their GitHub profile and request a secure route. Do not post details publicly while arranging contact.

Include the affected commit/version, exact component, minimal reproduction using synthetic documents, demonstrated impact, and redacted logs.

When optional hosted model providers are enabled, document contents may be sent to that provider. Review provider privacy settings before use. Do not describe the system as private or local-only unless the selected execution path is actually local.
